# Reproduce this demo — end to end

Everything here regenerates from one cited input file and two short scripts. No hidden state.

## Cited data (the only input)
**`frielingen9_xrf_4part.csv`** — 219 discrete samples, 15.4–249.8 m.
Source: **Thöle, H. et al. (2019)**, geochemistry / CaCO₃ / TOC of core **Frielingen-9** (Lower Cretaceous, eastern Lower Saxony Basin), **PANGAEA, https://doi.org/10.1594/PANGAEA.897615 (CC-BY 4.0)**; paper **https://doi.org/10.1002/dep2.83**. Columns: `depth_m, SiO2_pct, Al2O3_pct, Rb_mgkg, Zr_mgkg, CaCO3_pct, TOC_pct`. Only complete-suite rows are kept. SiO₂/Al₂O₃ are the composition's bulk parts; Rb/Zr (mg/kg) are scaled into the same closure; **CaCO₃ and TOC are held out as independent calibration targets — they are not in the composition.**

## Requirements
- Python ≥ 3.8, with **numpy** and **matplotlib** for the analysis:
  `pip install numpy matplotlib`
- The dashboard builder uses the **Python standard library only**.
- To view the dashboard: any modern web browser (open the `.html` file directly — it is fully self-contained, offline, no server).

## Two steps
```
python cnt_cnq_analysis.py     # CSV  -> figures + series + results + projector_data.json
python build_dashboard.py      # projector_data.json -> frielingen9_projector_16x9.html
```

### Step 1 — `cnt_cnq_analysis.py`
Reads the CSV and runs the documented Hs / CNT method (closure → CLR → Helmert-orthonormal ILR → per-step Aitchison step, helmsman, power-share / Activation Coefficient, K_eff, robust regime tripwire) plus the native **D = 4 CNQ** (radial magnitude + bearing rotation). Writes:

| Output | Contents |
|---|---|
| `mud_fig1_step_caco3.png` | CNT Aitchison step + regime flags vs independent CaCO₃ |
| `mud_fig2_helmsman.png` | helmsman (driver per step) + deceptive-drift markers |
| `mud_fig3_cnq.png` | CNQ native radial + step bearing-rotation |
| `frielingen9_cnt_cnq_series.csv` | **per-sample** table: closed parts, CLR, step, helmsman, regime, K_eff, CNQ radial, barycenter (x,y), log Si/Al, log Zr/Rb, CaCO₃, TOC, activation α |
| `frielingen9_results.json` | run summary (helmsman counts, directness, regime count, calibration r) |
| `projector_data.json` | the array bundle the dashboard reads |

### Step 2 — `build_dashboard.py`
Reads `projector_data.json` and writes the single-screen **16:9 dashboard** `frielingen9_projector_16x9.html` (chemostratigraphic log, CLR radar, barycenter trajectory + SHOCK, calibration scatter, per-depth readout, summary). The HTML embeds its data, so it is portable and works offline.

## Reproducibility notes
- **Deterministic.** Same CSV → identical numbers every run (the barycenter PCA uses a fixed sign convention so the trajectory is reproducible, not just up-to-a-flip).
- **Method, not engine binary.** These scripts are a *faithful, transparent reimplementation* of the documented CNT/CNQ method — readable end to end. They are **not** the hash-stamped canonical engine; running the same composition through that engine for byte-provenance is a listed next step.
- **What is generated vs. kept.** `frielingen9_projector_16x9.html`, the three `mud_fig*.png`, the two CSVs/JSON above are **generated** by the steps. `frielingen9_xrf_4part.csv` is the **input**. `frielingen9_projector.html` is a **static** detailed scroll-view variant kept for convenience (not regenerated by these two steps).
