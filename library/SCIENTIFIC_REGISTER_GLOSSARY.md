## The usage rule (how the register works)

> **In publication prose, the scientific term leads.** The in-house coinage may follow once, in
> parentheses, on first use — then the scientific term carries the rest of the document. Analogies are
> welcome but must be named as analogies. Internal docs, journals, and the library keep the full vivid
> vocabulary; this rule governs only **what has been written for publication.**

This is not a purge of the project's voice — the coinages are the brand and the memory. It is a
**front-of-house / back-of-house** split: the expert meets the precise term first and trusts it; the
evocative name rides alongside so nothing is lost.

## D · Claim-tier words to police (precision, not flavor)

These are not coinages — they are strong words that must be earned every time they appear in a paper:

- **lossless** → say *"reconstruction to the IEEE floor (residual ≈ 10⁻¹⁶)"*, not "lossless," unless literal.
- **exact** → fine when a measured bound is given (e.g. `≈ 4.4×10⁻¹⁶`); otherwise soften.
- **proves / proof** → reserve for the mathematics; for empirical results use *demonstrates / measures*.
- **universal** → avoid; use *domain-general candidate* and fence to T2/T3.
- **optimal** → only in the precise sense (e.g. mean-square-optimal Karhunen–Loève) with a citation.

> The publication set already practices this discipline well (P1 writes *"measured reconstruction, not
> 'lossless'"*; P7 writes *"not a universal law"*). This section makes the practice a maintained checklist.
