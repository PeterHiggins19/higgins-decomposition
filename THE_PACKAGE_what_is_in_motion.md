## The sniffer, pushed — and held (the headline measurement)

Stress-tested over 150 randomized runs per regime (`d871430ef12fdcb2`):

| push | reaches the true signal | note |
|---|---|---|
| baseline | **100%** (14 stations) | the data's geometry is the heading |
| heavy noise (3×) | **100%** (28) | the tetrode reads through it |
| heavy noise + octode (N=8) | **100%** (21) | more samples → cleaner, faster |
| rough terrain (ripple) | **99%** (48) | false local slopes do not fool it |
| strong decoy, pure gradient | 53% | a false peak can capture a blind climber |
| decoy + **a little exploration** | **72%** | exploration escapes the trap |
| **any push at once**, pure gradient | 9% | the worst case breaks blind ascent |
| any push + **exploration patrol** | **97%** (88) | it holds — you pay for the hard ones in exploration |

The reading is honest and useful: the sniffer is solid through realistic noise and terrain on the tetrode
alone; against decoys and the worst combined push, **a little exploration is the point** — it converts a 9%
into a 97%. The cost is stations; the operator sets the exploration budget for the difficulty. The one boundary,
stated plainly: a truly flat field has no heading to read — no method invents a gradient that is not there.
