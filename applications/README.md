# Applications

Pathways for applying the CNT/CNQ framework to specific domains.

## Status convention

Each subfolder or document is stamped with one of:

- **ACTIVE** — under active development, with at least one Investigation Catalog entry tracking progress
- **PILOT** — first measurement pilot underway
- **DEFERRED** — pathway preserved but not under active investigation; reactivation gates documented
