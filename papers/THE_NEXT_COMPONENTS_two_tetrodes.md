## Why this is the right build order

The tetrode standard is satisfied only by **independent** legs — four copies of one biased channel buy nothing.
The analysis picks the missing *independence axes*, so each new node adds genuinely new evidence: a behavioral
and a structural read where there was only linguistic and neural; blood, microbiome and respiratory where there
was only cancer-epidemiology. That is the discipline turned into a build queue.
