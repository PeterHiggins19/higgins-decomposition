This document lists every DATA-folder dataset that is **not** in the Phase 1 manifest (and therefore not yet in the citation-grade reference suite), with the explicit reason for the deferral and the adapter work each would require to land in Phase 2.

**Reason:** This folder holds the *output* of an earlier worked example (the 10-step pipeline visualization), not raw compositional input. There is no time-indexed CSV to feed to CNT v3 / CNQ v2. The folder is documentation, not data.
**To land:** N/A — these are reference plates. Cite the existing visualizations directly when referring to the worked example.

### `DATA/IIASA Data/`

**Status:** PARTIALLY COVERED — `iiasa_ngfs` (Phase 4 NGFS scenario) is in the Phase 1 manifest. The rest are deferred.
**Deferred items:**
- **NGFS Phase-4 zip archives** (3 files, ~750 MB total) — these are the source archives behind the manifest's `iiasa_ngfs` dataset; the pipeline-ready CSV is already extracted.
- **Antarctic regional climate model NetCDF files** (8 files, ~10 GB total: HIRHAM5, RACMO24p1, CESM2, EC-Earth3, UKESM under SSP1-2.6 / SSP3-7.0 / SSP5-8.5) — these are gridded climate model outputs, not compositional time series. Each grid point has a time series of climate variables (temperature, precipitation, surface mass balance), which is **not directly compositional**.
- **`iamc_db (1).xlsx` through `iamc_db (40).xlsx`** — IAMC scenario database snapshots (Integrated Assessment Models). These are scenario-by-scenario emission-pathway sheets in a wide format that requires per-scenario reshaping.
- **Forest cover zip files** (`for2000_*`) — geospatial forest-cover data; not directly compositional.

**To land NetCDF / forest cover:** Each grid cell would need a defensible compositional reading (e.g., land-cover-type fractions per cell, summing to unity). This is a substantial domain-specific design decision that should not be rushed.
**To land IAMC excel sweep:** Build an `iamc_adapter.py` that reads each `.xlsx`, identifies the sectoral-emission columns, applies closure, and writes one pipeline-ready CSV per scenario. ~2-4 hours of careful schema work; most scenarios are 5-7 sector carriers across 30-80 year horizons.
**Priority:** IAMC sweep is high value (40 distinct scenario instances, each a clean compositional time series). Land in Phase 2.

### `DATA/Nuclear/`

**Status:** PARTIALLY COVERED — `nuclear_semf` is in Phase 1. The rest are deferred.
**Deferred items:**
- **`raymond_nuclide_table.csv`** (1.9 MB, ~3000 nuclides × ~10 columns) — full nuclide table with binding energy, decay-mode fractions, half-lives. Could yield a separate "decay mode fraction" composition per nuclide (alpha, beta-minus, beta-plus, gamma, electron capture, spontaneous fission). That gives D ≈ 5-6 carriers across T ≈ 3000 nuclides indexed by (Z, A).
- **`raymond_valley_ame2020.csv`** — alternative view of the SEMF decomposition with Z-binning; overlaps with `nuclear_semf_input.csv` but uses a different bin policy.
- **`ame2020_parsed.csv`** — atomic mass evaluations; not directly compositional but feeds into binding-energy decompositions.
**To land decay-mode adapter:** Read `raymond_nuclide_table.csv`, extract per-nuclide decay-mode fraction columns, normalize to closure, write `nuclear_decay_modes_input.csv`. ~1 hour.
**Priority:** Medium — would expose a different aspect of nuclear structure (decay channels rather than mass terms).

## Phase 2 priority queue

Highest-value, lowest-effort additions to land in a follow-up session:

1. **World Bank FAO indicators** — 5 datasets, ~3 hours total (existing adapter template). High dataset count, low effort.
2. **Geochemistry Ball / Tappe / Qin / Stracke OIB** — 4 datasets, ~8 hours total. High scientific value (flagship domain).
3. **owid-energy primary-source composition** — adds ~50-100 country-trajectories. ~4 hours. Massive corpus expansion.
4. **IAMC scenario sweep** — 40 scenario instances. ~3 hours (one adapter, batch run).
5. **Nuclear decay-mode adapter** — distinct view of nuclear structure. ~1 hour.
6. **Traffic signal timing** — clean D=3 or D=4 example. ~3-4 hours.
7. **Monthly-grain EMBER** — finer time resolution for the 8 EMBER countries. ~1 hour.

Conservative Phase 2 estimate: 25-30 hours of careful adapter work to roughly **double the corpus** to ~35-40 datasets across all 14 domains.

## Phase 2 anti-priority

These items are deferred indefinitely with the explicit reason:

- **Acoustics** — folder contains outputs only, not raw input data.
- **Working_Example** — same; visualizations of a past worked example.
- **NetCDF climate model output** — gridded numerical output, not a natural compositional shape. Would need significant domain design.
- **PDF / DOCX / source-code files** anywhere in DATA — not data.
