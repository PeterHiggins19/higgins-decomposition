Hs kinematics

A deterministic instrument that reads the full motion of a composition — who is steering, where the weight is flowing, when it changed state — and tells you in plain words.

As far as the data can be known and not one step further, named for the navigator and the physicist at once, with a receipt anyone can re‑check.

If you have a composition, you have a reason to look

A composition is just parts of a whole, tracked in some order — an energy mix over years, gut bacteria over days, rock chemistry down a borehole, market sectors over months. Shape it as a table and run one line:

from hs_kinematics_engine import run
from hs_diagnosis import diagnose

say = diagnose(M, names)["narrative"]   # what your system is doing, in plain words
out = run(M, names)                     # the full state, named twice, + the floors + a hash

It returns a sentence like “X is steering; weight is moving toward A, B, C and away from D; it changed state 3 times; it runs in about 4 independent directions.” — and the complete numbers underneath.

What it reads (named for the navigator / the physicist)

Helmsman / velocity

which part is steering the change — often a small one.

Arrow of intent / momentum

where the weight is flowing, and whether it's a move or a churn.

Waypoints / phase transitions

when the system genuinely changed state.

Course directness / path efficiency

a clean trend vs wandering.

Degrees of freedom / dimensionality

how many things are moving at once.

Station‑keeping / equilibrium

it holds when there's nothing to resolve — and says so.

Why you can trust it

Deterministic — same input → same output → same hash, on any machine (demonstrated identical SHA‑256 on Windows and Linux). Gauge R&R ≈ machine epsilon — the analysis adds no measurement variation. Honest — it holds at rest, flags a fragile read, withholds below its confidence gate, and marks the boundary where structure runs out. Reproducible — a single‑cell engine, an R port, an annotated notebook, a designer specification, and a conformance test.

Built on, and grateful to, the CoDa community

Hˢ kinematics is an extension of standard compositional data analysis into dynamics — the geometry is CoDa's; the motion is the extension. It builds on Aitchison's log‑ratio geometry and the four decades of the CoDaWork community (Egozcue, Pawlowsky‑Glahn, Hron, Martín‑Fernández, Gloor, and many more), and on replicator dynamics and information geometry for the kinematics. Recognition, not invention.
